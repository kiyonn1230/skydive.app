# 企業写真の差し込み仕様

マッチングカードの背景に使う企業写真の要件です。
写真が揃うまでは、カードは自動生成のアバターで表示されます（写真が入れば自動で切り替わります）。

---

## 1. 必要な枚数と割り当て

14枚。ファイル名は**企業IDそのまま**にしてください（`c01.jpg` 〜 `c14.jpg`）。

| ID | 企業名 | 業種 | 撮ってほしい／探してほしい画 |

| `c02` | グローバル商事株式会社 | 商社 | 高層ビルのオフィス街、または港のコンテナヤード。落ち着いた青系 |
| `c03` | スタートアップXYZ | スタートアップ | 小さめの明るいオフィス。ホワイトボードと付箋。生活感があってよい |
| `c04` | 医療法人社団ハートケア | 医療・介護 | 明るい医療施設の廊下や待合。清潔感、緑や白 |
| `c05` | 大和建設エンジニアリング | 建設・不動産 | 建設現場を引きで。鉄骨・クレーン・ヘルメット |
| `c06` | クリエイティブスタジオNOVA | クリエイティブ | 撮影スタジオや制作机。機材と色数の多さ。暖色 |
| `c07` | フューチャーファイナンス株式会社 | 金融 | ガラス張りの会議室、落ち着いたオフィス。ネイビー／グレー |

## 2. 写真の要件

### サイズ・向き
- **縦長 3:4**（カードが縦長のため）
- 最低 **1200 × 1600px**。これより大きい分には問題ありません（こちらで圧縮します）

### 写ってはいけないもの
- **人物の顔** — 後ろ姿・手元・遠景のシルエットは可。顔が判別できるものは使いません
  （求職者が企業を選ぶ画面です。人物が主役になると、この事業では意味が変わります）
- **実在企業のロゴ・商標・読める看板**
- **ナンバープレート、社員証、モニターに映った実データ**

### 構図
- **下から1/3が暗いか、平坦な画**を選んでください
  カード下部に企業名とマッチ度を白文字で重ねるため、そこがごちゃついていると読めません
- 主役が中央〜上寄りにあるものが収まりがよいです

### ライセンス
- **商用利用可・帰属表示不要**のもの（Unsplash License / Pexels License / CC0 など）
- 出典とライセンス種別を、ファイル名とは別にメモで残しておいてください。
  商談で「この画像は何ですか」と聞かれたときに答えられる必要があります

---

## 3. 渡し方

このディレクトリ（`assets/`）に置いて push するか、チャットに添付してください。

こちらで以下を行います。

1. 900 × 1200 / JPEG 品質72 に圧縮（1枚あたり80〜120KB程度）
2. 写真から主要な色を抽出し、カードごとの背景トーンに反映
3. data URI として `index.html` に埋め込み

**元ファイルはリポジトリに残しません。** このデモは「単一HTMLファイル・外部通信なし」が
商談上の売りなので、画像も本体に埋め込む必要があるためです。
埋め込み後、`assets/` には この仕様書と出典メモだけが残ります。

---

## 4. 揃わない場合

14枚すべてが揃わなくても動きます。
写真が無い企業は自動生成のアバターで表示されるので、**先に用意できた分から差し込めます**。
「まず3枚だけ」でも構いません。
