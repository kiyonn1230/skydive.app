# SwipeCA — 営業デモ

人材紹介会社向け AIマッチングSaaS「SwipeCA」の、**提案用デモ**です。

**▶ [デモを開く](https://kiyonn1230.github.io/skydive.app/)**

---

## このデモについて

- 表示される企業・候補者・面接ログは**すべて架空のダミーデータ**です
- **外部への通信は一切行いません**。入力内容はブラウザ内（localStorage）にのみ保存されます
- 単一のHTMLファイルです。ダウンロードしてダブルクリックでも開けます（オフラインで動作します）
- 実在の企業・個人とは関係ありません

## 使い方

画面右上の「⚡ 商談用データ」を押すと、全画面にデータが入った状態になります。
はじめての方は「🎬 ガイド」で、14ステップの案内を順に見てください。

### 切り替えられる画面

| ロール | 内容 |
|---|---|
| 求職者 | プロフィール入力 → AI分析 → スワイプ → 面接ログ → 面談予約 |
| CA | 担当求職者の進捗管理・要対応の自動検知・売上達成率 |
| RA | 担当企業の求人枠の充足状況 |
| 企業 | 自社に応募した候補者のみを表示する企業ポータル |
| 経営 | 成約率・CAごとの生産性・導入効果シミュレーション |

求職者画面は、右上のトグルで**スマホ表示 / PC表示**を切り替えられます。

## 主な機能

- **説明できるマッチング**：スコアはランクだけでなく、5因子（業界適性・強みの一致・価値観の一致・勤務地・年収）の内訳を必ず併記します
- **応募＝情報提供への同意**：「興味あり」の段階では企業に情報は渡りません。応募時に、渡る情報・渡らない情報・利用目的・保存期間・撤回方法を提示し、同意を得てから開示します
- **面接ログの共有**：同じ企業を受けた候補者の質問・意図・通過理由を、匿名化したうえで共有します。面接を受けた本人が投稿できます
- **収集禁止項目の検知**：職業安定法5条の5で収集が禁止されている項目が入力された場合、保存を行いません
- **保存前マスキング**：氏名・学校名・連絡先などは、保存する前に伏せ字化されます
